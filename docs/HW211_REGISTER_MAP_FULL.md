# HW211 `dtu_wifi` full register map (appendix)

Complete Modbus register extract for the **`dtu_wifi`** sheet of the EVO270-1 /
HW211 protocol workbook. This is the appendix to
[`HW211_REGISTER_COMPARISON.md`](HW211_REGISTER_COMPARISON.md).

**Source:** [sjtrny/esphome-hw211](https://github.com/sjtrny/esphome-hw211)
`protocol/hw211_modbus.json` → `sheets.dtu_wifi` (226 rows), generated from
`datasheets/EVO270-1_MODBUS communication_protocol_6.5.25.xlsx`.

**Do not invent mappings.** Empty workbook cells are left blank. Do **not** mix
with the parallel `hw211` sheet (different telemetry addresses) — see the
comparison doc.

Detailed research extracts also live in:

- `docs/_research_hw211_esphome.md` (full both sheets + forks)
- `docs/_research_hitemp_cloud.md`
- `docs/_research_foxair_phnix.md`
- `docs/_research_github_sweep.md`
- `docs/_research_github_deeper.md` (Darksplat field CSVs — aliases only; no new addresses)

## Darksplat field companion (no extra register rows)

[Darksplat/EVOHeat-EVO270-ESP32-Modbus](https://github.com/Darksplat/EVOHeat-EVO270-ESP32-Modbus)
(`data/core_registers.csv`, `data/status_bits.csv`) is a field-verified EVO270-1
/ HW211 slave-**99** implementation that credits the sjtrny JSON.

**Register addresses:** same as this `dtu_wifi` appendix (1011–1013, 1104,
1129–1141, 1151–1156 clock mailbox, 2019–2025, **2050** / **2051** / **2085**,
2060–2062). **No additional Modbus addresses** beyond the sjtrny workbook were
published there.

**Bits:** same positions as State0/State1 above. Naming uses **legacy Aqua Temp
O10–O15** on bits that this workbook labels **O12–O17** (anodes / shutdown /
DTU online / defrost / hot-water). Prefer workbook labels here; see comparison
doc §3.3a for the alias table. Darksplat also fills **2050 bit 1** as S02
(over-heat) where this sheet’s text leaves bit 1 blank — verify against xlsx
before treating as official `dtu_wifi`.

**Fault0 `2085`:** Darksplat documents non-zero = fault active only; the
per-bit P/E table in this appendix (from sjtrny) remains the fuller source.
